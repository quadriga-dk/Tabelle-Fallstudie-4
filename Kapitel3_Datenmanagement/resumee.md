# Resümee

In diesem Kapitel wurde aufgezeigt, wie ein Datenmanagementplan (DMP) angelegt werden kann. Dabei werden die zur Veröffentlichung vorgesehenen Forschungsdaten anhand von ausgewählten Fragen beschrieben. Dies geschieht unter Beachtung der fachspezifischen Gepflogenheiten und so standardisiert wie möglich.

Die Beschreibung der Daten mit Metadaten und die Erstellung einer README-Datei stellen sicher, dass die Daten für den Upload in ein Repositorium bereit sind. Dieser Schritt wird im nächsten Kapitel beschrieben. 

Wenn Sie alle Unterkapitel durchgegangen sind und die nachfolgende Übung absolviert haben, sollten Sie:
- Bestandteile eines DMP benennen sowie
- einen DMP bei RDMO anlegen können.

Folgende wichtige Punkte sollten Sie darüber hinaus mitnehmen:

```{admonition} Keypoints
:class: keypoint

**Datenorganisation**
- Forschungsdaten müssen vor der Publikation geordnet, geclustert und in einem Datenmanagementplan (DMP) dokumentiert werden. Ziel ist, dass die Daten auch projektextern verständlich sind. Für das Erstellen eines DMP stehen Tools wie RDMO zur Verfügung.
- Die Dateibenennung sollte konsequent sein und nach Möglichkeit vom Projekt übernommen werden. Die im Projekt gewachsene Struktur ist meist sinnvoll und logisch. Eine Veröffentlichung von Forschungsdaten in "Paketen" die der Struktur folgen ist daher zu empfehlen.

**Erschließung**
- Metadaten sollten disziplinspezifischen Standards bzw. den etablierten Konventionen der Fachcommunity folgen.
- Legen Sie eine README-Datei als einfachste Form der Datendokumentation an. Diese stellt sicher, dass Dritte die Daten und deren Entstehungskontext korrekt einordnen können. 
```
