# Resümee

Im zurückliegenden Kapitel wurden Schritte erläutert, die die Publikation von Forschungsdaten ermöglichen. 

Dabei haben Sie erfahren, wie Sie:
- sich einen Überblick über Repositorien als Publikationsplattformen verschaffen,
- Daten auf Zenodo publizieren,
- und die erfolgreiche Publikation über verschiedene Kanäle kommunizieren können.

Dabei ist deutlich geworden, dass die FAIRness Ihrer Daten maßgeblich vom Persitenten Identifikator (z. B. ein DOI), einer umfangreichen und standardisierten Beschreibung der Daten mit Metadaten, der Wahl offener Formate, der Angabe qualifizierter Referenzen und dem Bereitstellen einer ausführlichen Dokumentation bestimmt wird.

Wenn Sie alle Unterkapitel durchgegangen sind und die nachfolgende Übung absolviert haben, sollten Sie nun:
- ein Repositorium auswählen,
- den Begriff Datenpublikation erläutern sowie
- Beispiele für die Wissenschaftskommunikation nennen können.

Folgende wichtige Punkte sollten Sie darüber hinaus mitnehmen:

```{admonition} Keypoints
:class: keypoint

Publizieren Sie Ihre Daten nach Möglichkeit in einem fachspezifischen Repositorium. Sollte ein solches nicht zur Verfügung stehen, können Sie die Forschungsdaten in einem institutionellen oder einem generischen Repositorium wie Zenodo veröffentlichen. 

Zur FAIRifizierung Ihrer Forschungsdaten können Sie Checklisten und Tools verwenden und das Ergebnis automatisiert prüfen lassen, um die Nachnutzungsmöglichkeit der Daten zu optimieren.

Für die **Kommunikation** der Veröffentlichung von Forschungsdaten kommen neben klassischen Mitteilungskanälen (Pressemitteilung, Social-Media-Post) auch spezielle Formate in Betracht (Data Stories). Es gilt zu prüfen, welche Zielgruppen erreicht werden sollen. Möglicherweise ist es sinnvoll, mehrere Kommunikationskanäle zu bedienen.
```
